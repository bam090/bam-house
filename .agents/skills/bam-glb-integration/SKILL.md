# 밤하우스 GLB 적용

1. 모델별로 장면의 대응 오브제와 사용할 파일을 확인한다. 같은 오브제에 여러 파일이 있으면 사용자의 버전 선택을 우선한다. 로컬 축, 바운딩 박스, 실제 접점, 텍스처와 외부 참조를 확인한다.
2. 기존 모델 로더와 배치를 활용한다. 원본 비율을 기준으로 크기와 방향을 맞추고 벽, 상판, 바닥과의 접점을 맞춘다. 금속과 투명 재질은 원본 재질 의도를 살린다.
3. 이동에 영향을 주는 모델은 실제 외곽과 발판 높이를 충돌 판정에 맞춘다. 바닥 접근, 걸어서 막혀야 할 면, 점프 착지, 발판에서 벗어나기, 양방향 통로를 확인한다. 변경 구역 경로를 재현하고 `node scripts/check-walk.ts`와 `npm run build`를 실행한다.
4. 마지막에 3D 모델링과 공간 배치 관점에서 브라우저 장면을 검수한다. 모델마다 일반 플레이 시점과 결함이 드러나는 근접·사선·측후면에서 구멍, 날카로운 돌출, 모난 윤곽, UV 늘어짐, 노멀과 재질 이음새, 뒤집힌 면, 겹침과 들뜸을 확인한다. 이상을 수정하고 같은 각도에서 다시 확인한다. 실제 확인 화면, 동선 결과와 남은 결함을 보고한다.
