2026-11-17. 사용자가 동작 연결 전에 정지 자세부터 확인하도록 요청한 작업이다.

- 미리보기: `/snowdrop-static-poses.html`. `pose=sit|lie`, `view=both|front|side`로 자세와 시점을 지정할 수 있다.

## 자세 구성

앉기는 뒷발을 앞발 뒤로 옮기고 골반을 낮췄다. 허벅지 표면은 관절 회전만으로 접지 않고 자세 전용 보정으로 둥근 부피를 유지했다. 눕기는 뒷발을 몸 아래로 모으고 가슴과 배를 낮췄다. 앞팔은 앞으로 뻗고, 메시보다 뒤에 있던 앞다리 기준점을 다시 맞췄다. 발목 주변에는 앞팔 단면을 이어 주는 표면 보정을 적용했다.

화면의 ‘설계 기준점’은 리그를 맞추기 위한 관절 목표다. 최종 표면에는 별도의 보정이 적용되어 있으므로 표시된 점이 완성된 스키닝을 뜻하지 않는다. 두 정지 형태를 확인한 다음 리그와 보정 형태를 연결하고 전환 중 접지·겹침을 검증해야 한다.

## 실제 확인

- 브라우저에서 앉기와 눕기의 정면·옆면을 각각 확대해서 확인했다. 뒷발 전진, 엉덩이 접지, 앞발의 나란한 배치와 눕기 앞팔의 높이를 확인했다.
- 브라우저 오류 로그 0건. 자세·시점 선택과 해당 GLB 링크를 확인했다.
- 전체 메시 최저 높이 0. 네 발의 바닥 간격은 모델 높이 1 기준 최대 0.000913이다.
- 눕기 앞팔 영역의 최고 높이는 0.0701이다. 이 수치는 표면 높이 검사이며 움직임의 자연스러움을 검증하는 값은 아니다.
- 원본 SHA-256, 세 텍스처의 원본 바이트와 UV 보존을 확인했다. 얼굴 상부는 평행 이동을 제외한 변형 오차가 1.5e-8 이하다.
- 생성 스크립트의 접지·얼굴·앞팔 검사, 변경한 JavaScript의 Oxlint, `npm run build` 통과.
- Blender 4.5.10에서 두 메시를 불러와 각각 37,416개 정점과 애니메이션 없음 상태를 확인한 뒤 저장했다.

실제 캡처는 `docs/snowdrop-review/static-{sit,lie}-{front,side,front-side}.jpg`에 저장했다. 이번 결과는 정지 형태 검토용이며 이동·앉기·눕기 사이의 전환과 밤하우스 씬 적용은 포함하지 않는다.
