# 3D 모델 설계서 작성 및 생성 규칙 (밤하우스 공통 기준)

새 3D 오브제와 승인 시안을 설계하고 GLB로 제작할 때 아래 일곱 기준을 개별 설계서 본문에 명시하고 모델 생성 및 배치 코드에 반영한다.

## 1. 좌표계, 팔레트, 공간 맞춤 스케일링

- 모델의 바닥 접점은 Y = 0에 맞춘다. 외곽 바운딩 박스의 중심을 바닥에 투영한 점을 원점 (0, 0, 0)으로 잡는다. 정면은 +Z, 좌우는 X, 위는 +Y로 정의하고 장면 배치 좌표와 회전각을 기록한다.
- [집 명세](house-spec.md)와 장면 좌표를 기준으로 배치 구역의 면적, 거실 층고 3.5m, 창문과 문의 위치 및 개폐 공간, 인접 벽과 가구, 고양이 통로를 확인한다. 필요한 여유를 제외한 최대 허용 치수(폭 × 깊이 × 높이)를 기록한다.
- 시안에서 폭·깊이·높이 비례를 산정하고 세 축에 같은 배율을 적용한다. 이미지로 확정할 수 없는 치수는 추정값으로 표시한다. 최대 배율은 각 축의 허용 치수를 시안 기준 치수로 나눈 값 중 가장 작은 값이다. 천장 고정형 캣타워와 벽 선반은 해당 구역의 실제 층고와 벽 길이에 맞춰 재단한다.
- 주요 색상은 [palette.ts](../src/scene/palette.ts)와 조화를 이루게 정한다. 설계서에 색상 코드와 적용 부위를 기록한다. 꿀색 오크는 `#c8a67c`, 밝은 오크는 `#e3d2b4`, 그레이지는 `#b9ae9c`, 소파 나무는 `#b07a4a`를 기준으로 삼는다.

## 2. 끝단 핀치 방지와 모서리 마감

- 원통과 튜브, 곡선 쿠션의 끝단은 다단 반구형 캡 또는 쿼드 기반 베벨로 닫는다. 링 수나 베벨 분할 수를 명시하고 정점이 한 점에 급격히 모여 뾰족하게 튀어나오는 핀치를 막는다.
- 메시 생성 후 정점 노멀을 부드럽게 재계산한다. 끝단과 모서리, 이음부에 날카로운 음영이 생기는지 확인한다.

## 3. 곡면의 자기 교차 방지

- 팔걸이와 아치, 파이프, S자 곡선의 최소 중심선 곡률 반경과 단면의 최대 반경, 경로 및 단면의 세그먼트 수를 수치로 적는다.
- 중심선의 최소 곡률 반경을 단면의 최대 반경보다 크게 잡고 급한 굽힘에는 분할을 더한다. 완성 메시에서 자기 교차, 안쪽으로 접힌 면, 주름을 확인한다.

## 4. 스무딩 후 디테일 깊이

- 채널 퀼팅과 플루티드 원목, 몰딩의 음각과 양각 치수를 정한다. 홈의 최소 완성 깊이는 용도에 따라 0.035~0.045m 범위에서 정하고 필요한 경우 더 깊게 잡는다.
- 디테일 경계에 지지 엣지 루프를 배치하고 스무딩과 서브디비전 후 완성 메시에서 깊이와 음영을 확인한다.

## 5. PBR 재질과 UV

- 재질별 텍스처, UV 타일링 밀도(반복 횟수/m), Bump 또는 Normal 맵 강도, Roughness를 수치로 기록한다. Roughness는 부클레·스톤·해초 0.85~0.95, 원목 0.65~0.75, 무광 금속 0.30~0.40을 기준으로 정한다.
- 넓은 면과 굽은 끝단에서 직물과 나뭇결 무늬의 크기가 일정한지 확인한다. 장면 조명에서 표면의 미세한 결, UV 이음새, 얼룩을 확인한다.

## 6. 부속 소품 접촉과 고양이 충돌

- 쿠션과 장식 소품마다 기준 표면에 닿는 좌표와 기대는 각도를 기록한다. 배치 후 접촉점에 틈이 생기거나 소품이 표면을 뚫는지 확인한다.
- [walkable.ts](../src/scene/walkable.ts)의 윗면 높이(`groundHeight`)와 Collider를 새 메시의 실제 외곽과 밟을 수 있는 표면에 맞춘다. 근사가 필요하면 허용 오차를 기록한다. 고양이의 접근, 우회, 통과, 점프와 착지를 확인한다.

## 7. GLB 출력과 다각도 검수

- 텍스처를 내장한 단일 `.glb`로 내보내고 프로젝트 모델 폴더인 `public/models/`에 저장한다.
- 장면에 배치한 뒤 정면, 앞쪽 사선, 측면, 근접 뷰에서 비율 왜곡, 이음새 틈과 텍스처 얼룩, 인접 벽·가구 및 고양이 동선과의 간섭을 확인한다.
- 모델과 장면 변경 후 `npm run build`와 `node scripts/check-walk.ts`를 통과시킨다.
