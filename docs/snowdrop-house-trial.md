# Snowdrop 밤하우스 시험 적용

> 2026-11-17 갱신: 기본 씬과 비교 화면은 이제 `snowdrop-volume.glb`를 사용한다. X는 앉기, C는 눕기다. 아래 내용은 최초 시험 적용 기록이며 최신 표면·전환 수정과 검증은 [공통 리그 수정 기록](snowdrop-volume-review.md)을 따른다.

2026-11-16. 기존 고양이는 그대로 보존하고 Snowdrop을 선택할 수 있게 연결했다.

## 확인 화면과 조작

- 밤하우스: http://127.0.0.1:5173/?cat=snowdrop
- 기존 고양이: http://127.0.0.1:5173/?cat=legacy
- 원본·작업본 비교: http://127.0.0.1:5173/snowdrop-review.html

X는 앉기와 일어서기를 전환한다. 눕기는 화면의 버튼으로 전환한다. 이동하거나 점프하면 일어난다. 귀 털기는 가만히 있을 때 8~16초 간격으로 발생하며 주요 가구의 외곽 0.65m 안에 들어왔을 때도 반응한다. 반응 후 10~16초 동안은 다시 발생하지 않는다. 가구 옆에 계속 서 있어도 접근 반응이 반복되지는 않는다. 앉거나 누운 상태에서도 귀만 움직인다.

화면의 고양이 선택 메뉴에서 즉시 기존 고양이로 돌아갈 수 있다. 모델 로드에 실패하면 기존 고양이로 전환한다. ‘시험 위치와 상태’에는 위치 이동과 짧은 이동·점프 버튼, 현재 속도와 점프 높이가 있다.

## 작업본

- 씬용: `public/models/characters/snowdrop/snowdrop-player.glb`
- 비교 화면용: `public/models/characters/snowdrop/snowdrop-interactions.glb`
- 편집용: `public/models/characters/snowdrop/snowdrop-interactions.blend`

원본 Meshy·Skater Cat 파일은 보존했다. 28개 뼈와 Walk·Sit·Lie·Jump·EarFlick 5개 클립을 사용한다. 정수리 정점은 귀 뼈에서 제외했다. 앉기와 눕기는 사용자가 추가한 정면·측면·윗면 레퍼런스를 참고했고 관절 접힘을 완화하는 보정 형태 두 개를 포함했다. 원본 재질과 내장 JPEG 3장의 바이트는 유지했다.

씬에서 고양이 높이는 0.64m다. 후속 요청에 따라 이동 속도를 3.00m/s로 낮췄다. 점프 중 수평 이동도 같은 속도를 사용한다. Run은 추가하지 않았다. 발이 느리다는 추가 피드백에 따라 Walk 재생 상한을 2.5배에서 4배로 올렸다. 최고 속도에서 한 주기는 약 0.28초다. 점프 높이는 Player 물리에서만 계산하며 GLB의 중복 상승은 제거한다. 실내에서 접점을 알아보기 쉽도록 지면에 있을 때만 옅은 접지 그림자를 표시한다.

## 실제 확인

- 브라우저에서 X 키 앉기, 기존 고양이로 전환과 복귀를 확인했다.
- 속도를 낮추기 전 이동 중 상태 표시가 4.00m/s인 것을 확인했고 빠르게 조정한 걷기의 연속 프레임을 저장했다.
- 거실 계단을 올라가 바닥 높이 1.40m에 도착하고 내려와 0.50m로 복귀했다.
- 제자리 점프의 최대 상승은 약 0.76m였다. 소파 앞에서 점프해 좌판 높이 약 1.85m에 착지한 뒤 걸어서 내려왔다.
- 실제 씬에서 자동 귀 털기가 발생했고 비교 화면의 얼굴 근접 시점에서 정수리가 갈라지지 않는 것을 확인했다.
- 앉기·눕기의 정면과 측면, 눕기의 윗면을 확인했다. 증거 화면은 `docs/snowdrop-review/`에 저장했다.

`check-snowdrop.mjs`와 `--player` 검사는 각각 1,205개 시점에서 메시의 바닥 침범·반복 경계·접지 속도·가중치·원본 텍스처를 확인한다. `check-cat-motion.ts`는 자세 전환, 귀만 겹쳐 재생하기, 접근 반응 대기 시간, 자동 귀 털기와 중복 점프 상승 방지를 검사한다. `check-walk.ts`는 기존 이동·가구 경로를 검사한다.

## 다리 접힘 후속 수정

눕기 앞다리의 좌우 굽힘을 줄이고 앞발을 앞으로 뻗도록 바꿨다. 앉기와 눕기에서 뒷발을 지나치게 앞으로 당기던 설정을 제거하고 골반 높이와 기울기를 조정했다. 생성 중 모든 앉기·눕기 시점에서 무릎이 골반 위로 뒤집히지 않는지와 앞다리의 옆 방향 변위가 0.025 모델 단위 미만인지 검사한다. 두 작업본 모두 관절 도달 거리 오차가 0이고 바닥·반복 경계 검사를 통과했다. 씬의 이동 상태 표시에서도 3.00m/s를 확인했다.

## 남은 제약

3m/s도 이 고양이 크기에서 자연스러운 걷기 속도보다 빠르다. 발 동작을 빠르게 조정했지만 완전한 발 고정은 되지 않아 미끄러짐이 남는다. 계단과 굽은 소파 표면에 네 발을 각각 맞추는 지형 IK는 없으므로 높이가 다른 곳에서는 일부 발이 뜰 수 있다. 눕기의 뒷다리와 골반 접힘은 근접 시점에서 다소 뭉쳐 보인다. 밥 먹기와 오브제별 자세·위치 정렬은 이번 구현에 포함하지 않았다.

## 재생성

```sh
node scripts/build-snowdrop.mjs
node scripts/build-snowdrop.mjs --player
node scripts/check-snowdrop.mjs
node scripts/check-snowdrop.mjs --player
node scripts/check-cat-motion.ts
node scripts/check-walk.ts
npm run build
```

Blender에서 `scripts/save-snowdrop-blend.py`를 실행하면 비교 화면용 GLB와 같은 데이터로 편집용 사본을 갱신한다.
