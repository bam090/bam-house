# Snowdrop 앉기 옆면과 공통 리그 수정

> 아래는 이전 수정 기록이다. 뒷발 가려짐·허벅지 돌출·꼬리 납작해짐의 후속 수정과 현재 검증 결과는 [뒷발·꼬리 수정 기록](snowdrop-paw-tail-fix.md)을 기준으로 한다. 현재 작업본은 보조 뼈를 포함해 30개 뼈와 국소 자세 보정을 사용한다.

2026-11-17. 앉기 옆면과 엉덩이·다리의 표면 파손을 수정했다. 걷기·앉기·눕기·점프·귀 털기의 몸 변형과 동작 전환을 확인했다. 조작은 X 앉기, C 눕기이며 이동 속도는 3.00m/s다.

## 검토 화면과 작업본

- 정지 자세: `/snowdrop-static-poses.html?pose=sit&view=side&rig=volume`
- 원본과 동작 비교: `/snowdrop-review.html`. ‘자세 전환’, ‘뒤에서’, ‘뒤 사선’으로 실제 런타임의 중간 프레임을 확인한다.
- 기본 밤하우스: `/`. 이제 특수 쿼리 없이 수정 리그를 사용한다.
- 공통 리그: `public/models/characters/snowdrop/snowdrop-volume.glb`, `snowdrop-volume.blend`
- 공통 리그의 실제 마지막 프레임: `snowdrop-sit-volume-static.glb`, `snowdrop-lie-volume-static.glb`

사용자가 기본 씬에서 본 파손을 수정하도록 요청한 뒤 기본 Snowdrop도 수정 리그로 연결했다. 원본과 이전 `snowdrop-player.glb`는 보존했고 기존 고양이 선택 메뉴도 유지한다. 이전 파일은 `/snowdrop-review.html?rig=previous`에서 비교할 수 있다.

## 표면 파손 추가 수정

이전 기본 파일은 골반 가중치 오류와 역변형으로 만든 자세 보정을 포함하고 있었다. 브라우저의 뒤 사선 시점에서 엉덩이의 갈라진 면을 재현했다. 이전 파일의 전환 검사에서는 뒤쪽 메시 연결선이 최대 16.46배 늘어났고 수정 리그는 3.78배 이내였다. 미리보기에서만 쓰던 수정 리그를 기본 플레이어와 검사 코드가 함께 사용하도록 연결했다.

전환 도중 반대 자세를 요청할 때 아직 화면에 기여하는 동작의 재생 위치가 끝으로 뛰지 않게 했다. 일어서기 역재생은 6배에서 2.2배로 낮췄고 앉기·눕기 혼합과 공중 동작 진입을 완만하게 했다. 꼬리 클립의 시작 프레임에서도 쉬는 자세의 방향이 그대로 유지되도록 고쳤다. 모델의 뼈 길이나 몸통 크기를 바꿔 파손을 가리는 방식은 사용하지 않았다.

`check-cat-surface.mjs`는 실제 씬과 같은 애니메이터로 14개 전환·중간 입력·귀 털기·앉거나 누운 상태에서 점프하는 경우를 검사한다. 뒤쪽 연결선 42,821개와 중복 정점 쌍 5,501개를 검사했고 이음새 벌어짐은 0이었다. 정지 자세 전환의 최대 정점 이동량은 30Hz 표본에서 0.0759 모델 단위였다. 빠른 걷기의 발 왕복은 별도로 보고하며 정지 전환의 이동량 기준을 적용하지 않는다. 이 검사는 표면 늘어남과 이음새·시간 연속성의 회귀 검사이며 모든 삼각형의 자기 교차를 완전히 판정하는 검사는 아니다.

결과는 `snowdrop-volume-surface-validation.json`, 수정 전 기준은 `snowdrop-player-surface-validation.json`에 저장했다. 설치된 Three.js와 Blender로 처리했으며 추가 의존성은 설치하지 않았다.

브라우저에서 수정 전후 앉기를 같은 뒤 사선 시점으로 비교했다. 수정본의 서기→앉기, 앉기→눕기, 눕기→앉기, 앉기→서기, 눕기→걷기 중간 프레임도 확인했다. 기본 5173 씬에서는 X/C 연속 입력과 누운 상태에서의 점프·착지 후 표면을 확인했고 오류 로그는 없었다. 캡처는 `docs/snowdrop-review/surface-*.jpg`에 저장했다. `surface-house-final.jpg`는 기본 씬에서 찍은 최종 뒤쪽 모습이다.

## 원인과 수정

가중치 배열의 빈 칸에 반복된 골반 인덱스와 0을 대입하면서 실제 골반 가중치를 덮어쓰는 오류가 있었다. 그 결과 엉덩이와 등 일부가 가슴 뼈를 따라 움직였다. 누적 방식으로 고치고 원래 골반에 붙어야 할 등 정점 249개의 가중치가 0.85 이상인지 검사한다.

골반과 뒷다리 관절도 실제 메시 안쪽으로 다시 맞췄다. 앉을 때 골반 중심은 높이 0.40에서 0.24로 내려가고 뒷발은 앞으로 0.35만큼 이동한다. 발 위로 허벅지가 접히고 그 뒤로 엉덩이가 내려오도록 구성했다. 수치는 키를 1로 정규화한 모델 좌표다.

새 작업본에는 기존 앉기·눕기 표면 보정을 적용하지 않는다. 몸을 축소하거나 바닥 아래 정점을 강제로 눌러 펴는 대신 뼈 길이를 유지하고 dual quaternion 스키닝으로 관절 회전 시 단면 수축을 줄인다. 눕기에서는 앞발의 강체 가중치 범위를 줄이고 손목 높이를 낮춰 앞팔에서 발등으로 이어지는 굴곡을 완화했다.

자세를 섞을 때 발이 원호를 그리며 바닥 밑으로 내려가던 문제는 발·손목 목표를 함께 보간한 뒤 다리 관절을 다시 푸는 방식으로 수정했다. 점프의 월드 높이는 기존 Player 물리만 담당한다. 정지 메시도 같은 리그와 변형식으로 추출하므로 별도 조형 메시와 런타임 사이의 불일치를 없앴다.

## 검증

- `check-snowdrop-volume.mjs`: Walk 121개 프레임, 나머지 4개 클립 각각 61개 프레임의 전체 정점 검사. 서기→앉기, 앉기→눕기, 눕기→앉기, 앉기→걷기와 물리 점프·착지 검사 통과.
- 검사 구간의 가장 낮은 정점은 모델 좌표 약 -0.00199다. 씬 크기 0.64에서 약 1.3mm이며 검사 허용치 0.006 이내다. 완전한 수학적 무관통을 뜻하지 않는다.
- 가슴·골반의 고정 정점군 분포 지표는 기준 대비 최소 약 0.988, 허벅지는 약 0.852였다. 이 값은 갑작스러운 수축을 찾는 회귀 지표이며 해부학적 부피나 자기 교차의 정확한 측정값은 아니다.
- `check-dual-quaternion.mjs`: 실제 웹용 변형 코드의 강체 이동·회전, 180도 회전 혼합의 반지름 보존, 부모의 0.64 배율과 회전에 대한 불변성 검사 통과.
- 원본 SHA-256, UV와 내장 텍스처 3장의 바이트 보존 확인.
- Blender 4.5.10에서 실제 고양이 메시 37,416개 정점, 뼈 28개, 동작 5개를 확인하고 Preserve Volume을 켠 작업본 저장.
- `npm run build` 통과. 변경 파일 Oxlint 오류 없음. Player의 기존 Fast Refresh 경고 2건과 번들 크기 경고는 남아 있다.
- 표면 수정 후 `check-cat-surface.mjs`, `check-cat-motion.ts`, `check-snowdrop-volume.mjs`, `check-dual-quaternion.mjs`, `check-walk.ts`를 확인했다. 사용자 제공 원본은 보존했다.

브라우저에서는 앉기·눕기의 앞·옆 모습, 걷기 25%·75%, 점프 준비·정점, 귀 털기의 머리 형태를 확인했다. 캡처는 `docs/snowdrop-review/volume-*.jpg`에 저장한다. 수치 결과는 `snowdrop-volume-validation.json`을 참고한다.

별도 밤하우스 씬에서는 C 눕기와 X 앉기, 3.00m/s 걷기, 제자리 점프 후 지면 복귀를 확인했다. 거실 바닥 점프의 표시 최고 상승량은 0.76m였다. 세 검토 화면에서 수집한 브라우저 오류 로그는 0건이었다. 시험 버튼을 누른 직후에도 X/C가 작동하도록 버튼 포커스 차단을 제거했다.

GLB 표준 자체는 이 커스텀 dual quaternion 셰이더를 포함하지 않는다. 동작 형태는 제공한 웹 미리보기나 Preserve Volume 설정이 있는 Blender 작업본으로 확인해야 한다. 일반 GLB 뷰어는 선형 스키닝을 사용해 다르게 보일 수 있다. 정지 GLB 두 개는 이미 변형된 메시이므로 이 제한이 없다.

3.00m/s에서 달리기 없이 걷기 주기 3배를 유지하는 기존 선택은 그대로다. 이 속도에서 남는 발 미끄러짐은 이번 볼륨 수정으로 해결됐다고 보지 않는다.

## 재생성

```sh
node scripts/build-snowdrop.mjs --volume
node scripts/export-snowdrop-volume-stills.mjs
node scripts/check-snowdrop-volume.mjs
node scripts/check-dual-quaternion.mjs
node scripts/check-cat-surface.mjs
node scripts/check-cat-motion.ts
```

Blender 작업본 저장 스크립트는 `scripts/save-snowdrop-volume.py`다. 현재 기본 플레이어는 `--volume`으로 재생성한다. `--player`는 보존된 이전 선형 스키닝 파일을 만드는 옵션이며 현재 기본 씬 파일과 다르다.
