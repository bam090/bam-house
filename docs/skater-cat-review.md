# Skater Cat 흰 장모·걷기 미리보기

2026-11-16에 원본 메시를 바탕으로 작업했다. 밤하우스 씬에는 적용하지 않았다.

이 문서는 FBX·정적 GLB 기반의 별도 리그 작업 기록이다. 이후 제공된 Blender 원본의 리그·털·Walk·run 확인과 레퍼런스 얼굴 수정은 [Blender 원본 검토 기록](skater-cat-source-review.md)에 정리했다.

## 열기와 작업 파일

- 개발 미리보기: http://localhost:5173/skater-cat-walk-review.html (`npm run dev`)
- 이번에 브라우저에서 확인한 빌드 미리보기: http://127.0.0.1:5189/skater-cat-walk-review.html (`npm run preview -- --host 127.0.0.1 --port 5189 --strictPort`)
- 빌드 후 미리보기: `npm run build`와 `npm run preview`를 실행한 뒤 `/skater-cat-walk-review.html`로 접속한다.
- 웹용 작업본: `public/models/characters/skater-cat/cat-angora-walk.glb`
- 재생성: `node scripts/build-skater-cat.mjs`
- 모델 검사: `node scripts/check-skater-cat.mjs`
- 수치 결과: `docs/skater-cat-validation.json`
- 브라우저 검수 화면: `docs/skater-cat-review/`

원본 `cat.fbx`, `cat.glb`와 기존 `skater-cat-review.html`은 보존했다. 새 미리보기에는 원본·작업본 비교, 재생·정지, 한 프레임 이동, 동작 위치 조절, 앞·옆·사선·얼굴 시점, 낮·그늘 조명, 부드러운 털 광택과 뼈대 표시가 있다. 두 카메라와 조명 조건은 동일하다.

## 모델과 걷기

25개 뼈로 구성한 스킨 리그와 `Angora_Walk_InPlace` 클립을 GLB에 저장했다. 클립 길이는 1.36초이며 245개 시점에 관절 자세를 기록했다. 네 발은 1/4 주기씩 순서를 두고 움직인다. 발마다 주기의 68%를 접지하고 나머지 구간에 발을 들어 앞으로 옮긴다. 두 관절의 역기구학으로 발목 위치를 구한 뒤 발바닥 방향을 유지한다. 머리와 꼬리에도 작은 움직임을 넣었다.

전체 높이를 1 단위로 정규화했고 glTF의 미터 단위를 기준으로 검사했다. 접지 구간의 발 속도는 약 0.173 단위/초다. 제자리 걷기에서는 발이 뒤로 움직이는 것이 정상이다. 미리보기의 이동 바닥을 켜면 바닥 선과 접지한 발이 같은 속도로 움직이는지 비교할 수 있다. 바닥은 클립이 반복되어도 연속해서 이동한다.

사용자의 피드백에 따라 개별 털을 표현하던 곡선 리본 메시를 제거했다. 목둘레와 꼬리의 부드러운 볼륨, 약한 표면 요철과 색 변화, 거친 표면의 은은한 광택으로 흰 털을 표현한다. 별도 웹 셰이더 없이 GLB 재질과 메시에서 같은 모습을 읽을 수 있다.

눈과 코는 여러 구체를 겹치는 방식에서 얼굴 표면에 밀착하는 얕은 곡면으로 바꿨다. 홍채의 파란색과 동공의 경계를 부드럽게 연결했고 코의 위치와 색도 조정했다. 주둥이의 돌출을 줄이고 아래 입술의 날카로운 접힘을 국소적으로 완화했다. 이전 작업본과 생성 스크립트는 `.models.local/skater-cat-v1/`에 보관했다.

## 확인과 수정

초기 버전은 Chrome에서 확인했고 얼굴·털 수정본은 앱 내 브라우저의 실제 WebGL 화면에서 확인했다. 가까운 얼굴과 정면·옆면, 낮·그늘 조명에서 눈과 입의 연결, 목둘레와 꼬리의 실루엣을 비교했다. 걷기 클립은 유지했으며 수정한 GLB로 접지와 루프 검사를 다시 실행했다.

초기 버전에서 수정한 문제는 다음과 같다. 개별 털 표현은 이후 사용자의 요청으로 교체했다.

- 바깥으로 뻗는 털을 아래로 빗은 방향으로 바꾸고 꼬리의 속털 볼륨을 보강했다.
- 리본 면 방향을 정리하고 가는 털이 만드는 과한 자기 그림자를 줄였다.
- 발이 접지로 전환되는 시점에 키프레임을 추가해 속도 오차를 줄였다.
- 배 중앙에 다리 가중치가 섞여 생기던 변형을 제거하고 관절 주변의 가중치를 부드럽게 연결했다.
- 반복 경계에서 이동 바닥이 튀던 문제를 고쳤다.

최종 GLB를 다시 불러온 검사에서 998개 시점을 확인했다. 키프레임 사이의 보간 구간도 검사에 포함한다.

| 항목 | 결과 |
|---|---:|
| 접지 높이 최대 오차 | 0.000882 mm |
| 발바닥 최저 높이 | -0.000642 mm |
| 접지 속도 최대 오차 | 0.0923 mm/s |
| 루프 시작·끝의 몸체 정점 최대 차이 | 0.00000735 mm |
| 배 주변 메시 모서리의 최대 길이 비율 | 원래 길이의 1.270배 |

이 수치는 정규화한 모델에서 계산한 결과이며 실물 고양이에 대한 측정값은 아니다. 전체 스킨 가중치의 합과 뼈 인덱스, 원본 GLB 해시도 검사했다. `npm run build`와 수정한 JavaScript·설정 파일의 `oxlint` 검사를 통과했다. 빌드에는 500 kB를 넘는 JavaScript 청크 경고가 남아 있다.

## 남은 범위

수정본은 약 1.94 MB이며 눈과 코를 포함해 49,130개 트라이앵글이다. 이전 버전의 약 23.2 MB, 260,102개 트라이앵글에서 줄었다. 이번에는 데스크톱 비교 미리보기까지 확인했다. 모바일 성능, LOD, 밤하우스 실제 조명과 이동 속도에 맞춘 보정은 아직 검증하지 않았다.
