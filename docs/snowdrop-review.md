## 외형과 뼈

입력은 37,416개 정점과 63,826개 삼각형으로 구성된 정적 메시다. 리그와 애니메이션은 없었다. 작업본은 원래 메시·UV·재질을 사용하며 내장 JPEG 텍스처 3장의 바이트를 그대로 유지한다. 크기만 전체 높이 1단위로 정규화했다.

JonasDichelle의 기존 리그에서 사용할 뼈 역할을 골라 새 모델의 관절 위치에 맞췄다. 원본의 순환 제약과 IK 제어기는 내보내지 않고 계산한 자세를 변형 뼈의 키프레임으로 저장했다.

| 부위 | 뼈 수 | 용도 |
|---|---:|---|
| 몸통·목·머리 | 4 | 자세와 고개 방향 |
| 턱 | 1 | 향후 씹는 동작을 위한 연결 |
| 좌우 귀 | 2 | 귀 털기 |
| 네 다리 | 16 | 각 다리의 위·아래·발목·발 |
| 꼬리 | 5 | 몸통과 분리한 꼬리 자세 |
| 합계 | 28 | 발가락·얼굴 세부 제어 뼈 제외 |

원본 뼈 이름과 새 관절 위치의 대응은 `public/models/characters/snowdrop/snowdrop-build.json`에 저장했다. 턱뼈를 남겼지만 씹기 클립과 입 안쪽 메시는 만들지 않았다.

## 저장한 동작

| 클립 | 길이 | 재생 방식 |
|---|---:|---|
| Walk | 1.125초 | 반복 제자리 걷기 |
| Sit | 1.3초 | 앉은 뒤 마지막 자세 유지 |
| Jump | 1.5초 | 웅크리기·도약·착지 후 기본 자세 복귀 |
| EarFlick | 0.72초 | 좌우 귀를 짧게 털고 기본 자세 복귀 |

Walk는 원본 클립에서 발이 들리는 시점과 주기를 읽어 발 순서를 맞췄다. 새 모델의 짧고 굵은 다리에 맞춰 보폭과 접지를 다시 계산했으므로 원본 키프레임을 그대로 복사한 동작은 아니다. 접지 비율은 68%, 보폭은 0.14단위, 이동 속도는 약 0.183단위/초다. Sit·Jump·EarFlick은 이번에 작성했다. 달리기는 포함하지 않았다.

Blender 파일은 외형 검토를 위해 Rest Position으로 저장했다. 동작 편집 시 Pose Position으로 전환하고 Walk·Sit·Jump·EarFlick 액션을 선택하면 된다.

## 검증

실제 브라우저의 WebGL 화면에서 정적 외형과 네 동작을 확인했다. 걷기의 앞·옆 모습과 반복 경계, 앉기 완료 자세, 점프 정점과 착지, 귀 털기의 얼굴 근접 모습을 확인했다. 앉을 때 꼬리 아래쪽이 바닥을 침범하던 문제를 수정했고 꼬리 끝의 몸통 가중치가 섞이던 부분도 분리했다.

`node scripts/check-snowdrop.mjs`에서 Walk 481개 시점과 나머지 클립 각각 181개 시점을 검사했다. 전체 1,024개 시점에서 메시 정점의 변환값과 바닥 높이를 확인했다. 텍스처 바이트, 스킨 가중치 합, 뼈 28개와 클립 4개도 검사했다.

| 측정 | 결과 |
|---|---:|
| 전체 클립의 최저 표면 높이 | 약 -0.00000065단위 |
| 걷기 접지 뼈의 최대 높이 오차 | 약 0.00000068단위 |
| 걷기 접지 속도 최대 오차 | 약 0.0000676단위/초 |
| 걷기 시작·끝 정점 차이 | 약 0.0000000081단위 |
| 점프·귀 털기 시작·끝 정점 차이 | 0 |

앉기는 시작과 끝이 다른 자세이므로 반복 경계 일치를 요구하지 않았다. 검증 수치는 모델 높이를 1단위로 정규화한 값이며 실제 게임 크기는 아직 적용하지 않았다. 상세 결과는 `docs/snowdrop-validation.json`에 있다.

변경 JavaScript의 oxlint 검사와 `npm run build`가 통과했다. 빌드에는 기존 대형 번들 경고가 남아 있다. Blender에서도 28개 뼈와 네 액션이 들어 있는 사본을 저장했다.

아직 구현하지 않은 범위는 밥 먹기·눕기 클립, 오브제 위치와 높이에 맞추는 기능, 게임 이동·충돌·점프 물리다. 원본 메시의 수염은 얇은 표면 형태이며 아주 가까이 보면 리본처럼 보일 수 있다.
