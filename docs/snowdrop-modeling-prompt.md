# 밤하우스 고양이 모델·동작 수정 프롬프트

밤하우스 플레이어 고양이의 자세·변형·표면을 수정할 때 사용한다. 이번 요청에 해당하는 항목을 적용하고 관련 없는 동작이나 외형까지 바꾸지 않는다.

## 방향

- 사용자가 지적한 부위와 동작을 먼저 확인한다. 고양이의 몸을 기준으로 좌우를 구분하고 문제가 보이는 시점과 전환 구간을 특정한다.
- 사용자 레퍼런스와 실제 고양이 사진을 대조한다. 앉기는 낮아진 골반, 앞으로 받치는 뒷발과 앞다리의 지지를 확인한다. 눕기는 가슴 높이, 팔꿈치·앞발의 접지와 접힌 뒷다리의 위치를 확인한다. 관찰한 근거를 변경 기준으로 적는다.
- 허벅지·엉덩이·꼬리의 부피를 유지한다. 뼈의 크기를 줄여 관절을 접거나 표면을 과도하게 수축시켜 결함을 숨기지 않는다. 얼굴·수염 등 요청 범위 밖의 승인된 외형은 보존한다.
- 현재 모델 경로와 동작 설정은 `src/scene/cat-motion.ts`에서 확인한다. 별도 변경 요청이 없으면 걷기 3m/s, X 앉기, C 눕기와 일어서기 후 이동 규칙을 유지한다.

## 제작

1. 프로젝트의 Blender 스킬 규칙을 따른다. 원본과 현재 적용본을 보존하고 별도 작업본을 만든다. 필요한 도구가 없으면 추가 설치 대상을 알린다.
2. Blender에서 메시·뼈·스킨 가중치를 확인한다. 자세 오류, 표면 겹침, 노멀 문제를 구분하고 이번 결함의 원인을 짧게 설명한다.
3. 골반·가슴·관절·발 위치로 정지 자세를 먼저 잡는다. 그다음 스킨 가중치와 관절 주변 메시를 수정한다. 남은 접힘에 필요한 보정 형상을 추가한다.
4. 앞·양옆·뒤에서 저비용 검수 렌더를 확인한다. 실루엣과 지지 자세가 자연스러워진 뒤 동작을 연결한다. 연결 후 끝 자세가 달라지지 않는지도 확인한다.
5. 자세 전환 중간의 부피와 발 접지를 보정한다. 여러 동작이 섞이는 구간, 역방향 전환, 전환 중 이동 입력도 확인한다. 기존 보정이 다른 자세의 표면을 밀어내는지 점검한다.

## 검증과 수정

- 저해상도 렌더에서 시작·중간·끝 자세를 직접 본다. 샘플 간격은 동작의 변화 속도에 맞춘다. 발이 닿는 순간과 짧은 혼합 구간을 별도로 확인하고 발견한 결함은 같은 시점에서 수정 전후를 비교한다.
- GLB를 내보낸 뒤 실제 웹 렌더링을 확인한다. Blender에서 보기 좋은 것만으로 완료하지 않는다. 기존 적용본과 작업본을 같은 조명·크기·카메라에서 비교한다.
- 일반 플레이 시점과 결함이 드러나는 근접 시점에서 발의 사라짐, 바닥 침범, 미끄러짐, 허벅지 찌그러짐, 꼬리 단면 손실, 돌출·틈·음영 이음새를 확인한다. 재생 화면과 중간 프레임 정지 화면을 함께 본다.
- 변경에 해당하는 기존 검사를 실행한다. 반복 결함은 가능하면 회귀 검사로 남기고 잘못된 입력에서 실패하는지도 확인한다. 수치 검사 통과를 시각적 검수의 대체 근거로 삼지 않는다.
- 눈에 보이는 깨짐이나 부자연스러운 지지 자세가 남으면 원인을 다시 확인하고 수정한다. 해결하지 못한 부분은 해당 각도와 프레임을 근거로 밝히며 해결했다고 보고하지 않는다.

## 산출물과 완료 조건

- 편집 가능한 `.blend`, 웹용 `.glb`와 재현에 필요한 생성 스크립트를 저장한다. 현재 요청에 씬 적용이 포함되면 되돌릴 기준 파일을 남기고 적용한다.
- 비교 미리보기 링크와 실제 확인 화면을 제공한다. 변경 내용, 실행한 검사의 결과, 남은 제약을 구분해 보고한다.
- 요청한 자세와 전환이 웹에서 자연스럽게 이어지고 관련 기능에 회귀가 없는지 확인한다. 승인된 범위의 수정·검증까지 마친 뒤 완료를 보고한다.
