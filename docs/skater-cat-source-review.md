# Blender 원본 동작과 레퍼런스 얼굴 확인

2026-11-16. 사용자가 제공한 `cat.blend`와 정면·측면·윗면 PNG 3장을 기준으로 확인했다. 이번 작업은 얼굴 수정과 원본 동작 검토용 미리보기이며 밤하우스 씬에는 적용하지 않았다.

기존 FBX·정적 GLB에는 없던 리그·동작·털이 Blender 원본에는 들어 있다. 이전에 만든 25개 뼈 제자리 걷기와 이번 원본 동작은 별개다. 이전 결과는 `skater-cat-walk-review.html`에서 계속 확인할 수 있다.

동작 길이는 프레임 개수를 fps로 나눈 값이 아니라 마지막 키와 첫 키 사이의 시간이다. 원본의 헤어 시스템은 GLB로 내보내지 않았다. 비교 화면의 원본도 웹용 흰색 재질과 단순 눈 재질로 표시하므로 Blender의 털 렌더 결과를 그대로 재현한 화면은 아니다.

## 얼굴 수정

원본 메시와 리그를 유지하면서 눈 간격과 눈 주변 비율을 조정했다. 눈은 회청색 홍채와 둥근 동공으로 바꿨고 돌출을 줄였다. 주둥이를 짧게 만들고 입 아래의 날카로운 주름을 완화했다. 작은 분홍색 코는 기존 표면에 색을 넣었으며 귀 안쪽에도 약한 분홍색을 적용했다.

새 눈은 Head 뼈에 연결했다. 원본 눈에는 코·귀의 가중치도 섞여 있었으므로 새 눈에 그대로 복사하지 않았다. 개별 털 대신 거친 흰색 표면과 은은한 광택을 사용했다. 원본 장모 실루엣과 털 시뮬레이션의 웹 재현은 이번 얼굴 비교본에 포함하지 않았다.

원본 액션의 키프레임은 수정하지 않았다. 작업용 Blender 사본에서는 헤어의 뷰포트·렌더 표시와 동적 계산을 껐으며 원본 파일의 설정은 보존했다.

## 실제 검증과 남은 문제

앱 내 브라우저의 실제 WebGL 화면에서 같은 조명으로 원본과 작업본을 비교했다. 정면·사선 얼굴, 낮·그늘 조명, Walk·run의 재생·정지, 0.25배 재생, 정면·측면과 시작·끝 자세를 확인했다. 로드 오류나 브라우저 콘솔 오류는 없었다.

원본 리그의 꼬리 Copy Rotation·IK와 척추 Pivot에서 Blender가 순환 의존성 9건을 경고했다. 웹 내보내기는 완료됐지만 동작 품질에는 다음 문제가 남는다.

- 다리를 크게 뻗을 때 가슴·겨드랑이 부근의 메시가 길게 늘어나거나 뾰족해진다.
- Walk의 몸통·다리 시작/끝은 수치상 거의 일치하지만 꼬리에는 차이가 남는다.
- run은 꼬리 외 뒷다리에도 시작/끝 차이가 남는다.
- 기본 자세의 바닥을 기준으로 움직이는 발이 바닥 아래로 들어가는 구간이 있다.
- 제자리 클립의 발이 뒤로 움직이는 것만으로 미끄러짐 여부를 판정하지 않았다. 실제 이동 속도와 접지 구간의 속도를 맞추는 검증은 아직 하지 않았다.

아래 값은 꼬리 끝까지 포함한 기본 자세 높이를 1m로 정규화한 상대 수치다. 실제 고양이 크기의 mm 값은 아니다. 각 파일·클립을 121개 시점에서 샘플링했다.

| 측정 | Walk | run |
|---|---:|---:|
| 시작/끝 최대 관절 위치 차이 | 약 40.93mm, 꼬리 | 약 51.23mm, 왼쪽 뒷다리 |
| 꼬리를 제외한 최대 관절 위치 차이 | 약 0.000034mm | 약 51.23mm |
| 시작/끝 최대 메시 정점 차이 | 약 37.76mm | 약 57.36mm |
| 기본 발바닥 정점의 최저 높이 | 약 -21.81mm | 약 -33.53mm |

GLB의 스킨 가중치 합, 75개 뼈, 두 클립의 길이와 유한한 변환값을 검사했다. `npm run build`와 변경 JavaScript의 oxlint 검사가 통과했다. 빌드에는 기존 대형 번들 경고가 있다. 이 결과는 데이터가 존재하고 재생된다는 검증이며 게임용 접지·루프 품질 통과 판정은 아니다.
