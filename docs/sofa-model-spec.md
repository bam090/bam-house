# 밤하우스 부클레 튜브 소파 3D 모델 설계서

승인된 목표는 폭 4.00m, 깊이 1.48m, 높이 1.12m의 아이보리 부클레 소파다. 좌석 높이는 0.45m다. [60번 측면 레퍼런스](research/60-sofa-boucle-tube-side.jpg)는 팔걸이 끝과 롤의 두께를, [61번 정면 레퍼런스](research/61-sofa-boucle-tube-front.jpg)는 가로 채널과 전체 비례를 판단하는 기준이다. [공통 설계 규칙](3d-model-spec-rules.md)을 적용한다.

## 1. 좌표계, 배치와 비례

GLB 원점은 바운딩 박스 중심의 바닥 투영점이다. 로컬 최저점은 Y = 0, 정면은 +Z, 좌우는 X, 위는 +Y다. [집 명세](house-spec.md)의 (1.50, −1.60)은 기존 초승달의 곡률 중심이다. 본체 중심은 여기서 장면 +Z로 2.85m 이동한 (1.50, 1.25)에 둔다. Y축으로 180° 돌려 통나무 탁자를 바라보게 한다.

| 항목 | 승인 기준 |
| --- | --- |
| 배치 구역 | X −0.70~3.70, Z 0.38~2.12. 면적 약 7.66m² |
| 허용 외곽 | 폭 4.40m × 깊이 1.74m × 높이 1.65m. 거실 층고 3.50m 안에서 스탠드 갓 하단에 0.10m를 남긴다. |
| 시안 비례 | 폭 1, 깊이 0.37, 높이 0.28. 사진에서 추정한 비례이며 크기를 조정할 때 세 축에 같은 배율을 적용한다. |
| 목표 외곽 | X −0.50~3.50, Z 0.51~1.99 |
| 인접 가구 | 탁자 (1.50, −0.85)까지 앞뒤 약 0.93m, 1인용 소파 (−1.00, −1.07)까지 앞뒤 최소 1.02m, 스탠드 받침까지 가로 0.70m |
| 통로 | 양끝과 뒤쪽에 0.50m 이상. 뒤쪽 기준선 Z 2.62까지 0.63m가 남는다. |

창문과 문의 개구부 및 개폐 구역을 장면에 겹쳐 간섭을 확인한다. 색상은 [팔레트](../src/scene/palette.ts)를 기준으로 아래 재질표에 명시한다.

## 2. 두 단 등받이와 끝단

등받이는 단일 연속 메시다. 안쪽 단면에 두 개의 타원형 볼록부를 형성해 위아래 튜브 롤이 포개져 보이게 한다.

| 요소 | 로컬 치수 |
| --- | --- |
| 위쪽 롤 | 중심 Y 0.96m, 상단 Y 1.12m. 수평 반경 0.18m, 수직 반경 0.16m |
| 아래쪽 롤 | 중심 Y 0.66m. 수평 반경 0.16m, 수직 반경 0.14m |
| 가로 홈 | 중심 Y 0.81m, 입구 폭 0.055m, 바닥 필렛 반경 0.012m. 목표 깊이 0.045m, 완성 메시 최솟값 0.040m |
| 팔걸이 끝 | 중심 Y 0.73m, 수평 반경 0.15m, 수직 반경 0.21m. 최저점 0.52m로 좌석보다 0.07m 위 |

앞끝은 경로에 접하는 반구형 캡으로 닫는다. 축 방향 돌출 길이 0.12m와 12구간, 둘레 48분할 이상으로 만들고 마지막 링까지 곡률을 이어 준다. 캡 접합부와 UV 경계의 정점 노멀을 부드럽게 맞춘 뒤 근접 뷰에서 핀치와 이상 음영을 확인한다.

## 3. U자 경로와 자기 교차

로컬 평면에서 중앙 (0, −0.55), 양쪽 (±1.25, −0.52), (±1.63, −0.30), (±1.79, +0.05), 캡 시작점 (±1.78, +0.38)을 경로 기준점으로 삼는다. 좌우를 대칭으로 만들고 중심선 곡률 반경은 최소 0.34m를 확보한다. 최대 단면 반경 0.18m를 적용할 때 안쪽에 0.16m 이상을 남긴다.

경로 160구간, 양쪽 굽힘 각각 32구간, 단면 48분할 이상을 쓴다. 앞쪽 마지막 0.64m에서 두 롤을 하나의 둥근 단면으로 합치고 상단은 중앙 1.12m에서 캡 시작점 0.94m까지 낮춘다. 완성 메시에서 접힌 면과 자기 교차를 확인한다.

## 4. 스무딩 후 디테일과 조립

- 홈의 양쪽 입구와 바닥에 지지 엣지 루프를 두고 스무딩 후 깊이를 확인한다. 정면과 사선 모두에서 두 볼록면과 홈의 연속된 음영이 보여야 한다.
- 좌석은 한 덩어리로 만든다. 앞선 중앙 Z +0.55m와 양쪽 끝 Z +0.74m로 오목한 앞선을 잡는다. 앞 가장자리 반경은 0.17m, 둘레 128분할과 단면 24분할 이상을 쓴다.
- 좌석 앞쪽만 라운딩하고 뒤쪽과 양옆 윤곽은 쉘 안쪽으로 들여 결합한다. 등받이와 팔걸이의 외곽은 원목 받침 상단까지 내리고 둥근 앞끝에 가까워지며 자연스럽게 올라오도록 한다.
- 원목 받침은 높이 0.045m로 만들고 좌석 하부 외곽보다 0.045m 들여 배치한다.

## 5. PBR 재질과 UV

| 재질 | 색과 텍스처 | Roughness | Normal 강도 | UV 반복/m |
| --- | --- | ---: | ---: | ---: |
| 본체 | 기존 GLB의 아이보리 천을 타일로 정리. 색상 목표 #eee3cf | 0.92 | 0.45 | 8 |
| 쿠션 | 그레이지 #b9ae9c를 기준으로 한 회갈색 #9b8472와 부클레 결 | 0.94 | 0.35 | 8 |
| 받침 | 소파 나무 #b07a4a와 길이 방향 나뭇결 | 0.70 | 0.18 | 3 |

Metallic은 모두 0이다. Normal 강도는 glTF의 `normalTexture.scale`이다. 본체와 쿠션에 부클레의 고리와 섬유 요철을 담은 Normal 맵을 내장한다. 천의 미세한 고리는 1~2mm로 보이게 하고 좌석과 팔걸이 끝에서 결의 크기가 일정한지 검수한다.

## 6. 쿠션 접촉과 고양이 충돌

원판 쿠션은 지름 0.42m와 0.49m를 두 개씩 쓴다. 두께는 지름의 약 3분의 1이다. 기울기는 수직에서 등받이 방향으로 잰다.

| 쿠션 | 좌석 접촉점 (X, Y, Z) | 기대는 지점 (X, Y, Z) | 기울기 |
| --- | --- | --- | ---: |
| 왼쪽 큰 쿠션 | (−1.40, 0.45, −0.10) | 등받이 (−1.40, 0.83, −0.33) | 23° |
| 왼쪽 작은 쿠션 | (−1.08, 0.45, +0.06) | 큰 쿠션 (−1.25, 0.71, −0.14) | 35° |
| 오른쪽 큰 쿠션 | (+1.40, 0.45, −0.10) | 등받이 (+1.40, 0.84, −0.33) | 20° |
| 오른쪽 작은 쿠션 | (+1.08, 0.45, +0.03) | 큰 쿠션 (+1.25, 0.73, −0.14) | 27° |

접촉점은 조립 목표값이며 완성 메시에서 보이는 틈을 5mm 이하로 맞춘다. 좌석 외곽을 바닥에 투영하고 `groundHeight`의 착지면을 0.45m로 맞춘다. 등받이와 팔걸이는 볼록 구역으로 나누고 캡 아래의 공간을 단면 높이에 맞춘다. 외곽 오차 0.04m, 착지면 오차 ±0.02m를 목표로 한다. 고양이 반경 0.22m는 한 번 적용하고 쿠션은 별도 착지면에서 제외한다. [걷기 규칙](../src/scene/walkable.ts)

## 7. GLB 출력과 인수 검수

텍스처를 내장한 단일 GLB를 `public/models/`에 저장한다. 외곽 치수 오차는 축별 ±0.01m, 바닥 접점 오차는 ±0.005m 이내다.

| 검수 뷰 | 확인 항목 |
| --- | --- |
| 정면 | 위아래 롤의 볼록함, 연속된 홈, 폭 대비 높이 |
| 앞쪽 30~45° 사선 | U자 흐름, 오목한 좌석 앞선, 쿠션 접촉, 가구 간격 |
| 측면 | 좌석 위에서 둥글게 끝나는 팔걸이, 끝단 아래 보이는 좌석과 받침 |
| 근접 | 핀치, 접힌 면, 0.040m 이상인 홈 깊이, 이음새와 텍스처 얼룩 |

각도 검수에서는 고양이를 숨기고 소파 중심을 기준으로 카메라를 돌린다. 동선 검수에서는 고양이를 표시해 탁자와 소파 사이, 양끝, 뒤쪽을 지나고 좌석에 점프로 착지한다. 창문과 문, 인접 가구와의 간격을 기록하고 `npm run build`와 `node scripts/check-walk.ts`를 실행한다.
