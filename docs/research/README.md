| 색 | 쓰는 곳 |
|---|---|

| 화이트 | 벽과 지붕과 침구와 소파 쿠션과 수전과 가전 |

## 사진을 쓰는 방법

- 사진의 분위기와 구성만 참고한다.
- 사진 속 제품의 고유한 디자인과 상표를 그대로 옮기지 않는다.
- 사진 파일은 다른 사람이 찍은 것이라서 공개 저장소에 올리지 않는다. `.gitignore`에 `docs/research/*.jpg`를 넣어 두었다.
- 이 README만 저장소에 올라간다.
